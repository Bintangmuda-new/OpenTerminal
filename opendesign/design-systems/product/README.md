# OpenTerminal product design system

Native WPF desktop terminal for DEMO market data. The interface is dense, data-first, and uses a black canvas with thin borders and compact widgets.

## Sources

- `desktop/MainWindow.xaml`: controls, colors, typography, spacing, borders and states.
- `desktop/MainWindow.xaml.cs`: responsive scaling and live semantic color updates.
- `desktop/App.xaml` and `desktop/App.xaml.cs`: application shell and rendering behavior.
- Supplied LIVE CANDLE screenshots: narrow-header spacing issue.

## Index

- `tokens/colors_and_type.css`: canonical extracted design tokens.
- `brand/style-notes.md`: visual and interaction foundations.
- `brand/voice-and-tone.md`: interface copy conventions.

These tokens document existing WPF code. They are not permission to redesign the workspace or introduce web UI.
